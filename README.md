## 🇬🇧 English

### Overview

A full-stack web platform developed for a document consulting services company, featuring:

- Institutional landing page
- Digital product sales
- Blog for publishing and sharing content

### Planned Tech Stack

| Area | Technologies |
|---|---|
| Frontend | Vite, React, React Router, Tailwind CSS |
| Backend | Node.js, Express |
| Authentication | JWT, bcrypt |
| Payments | Mercado Pago |
| Email | Nodemailer |
| Database | PostgreSQL |
| File Storage | AWS S3 |

### Project Status

Under development.
