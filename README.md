# JM web platform

> **English | [Português](#português)**

## 🇺🇸 English

A web platform for digital presence and content monetization, bringing together:

- Institutional landing page for brand presentation;
- Online store for selling digital products;
- Blog for content creation.

### Project Status

Early development (currently focused on the frontend).

### Technologies

#### Frontend

- TypeScript;
- React;
- React Router;
- TailwindCSS.

#### Backend (planned)

- Node.js + Express;
- Prisma ORM;
- PostgreSQL;
- SendGrid (email delivery);
- PagSeguro API (payments);
- Amazon S3 (storage with signed URLs).

## 🇧🇷 Português

Plataforma web para presença digital e monetização de conteúdo, reunindo:

- Landing page institucional para apresentação da marca;
- Loja online para venda de produtos digitais;
- Blog para produção de conteúdo.

### Status do Projeto

Em desenvolvimento inicial (foco atual no frontend).

### Tecnologias

#### Frontend

- TypeScript;
- React;

#### Backend (planejado)
