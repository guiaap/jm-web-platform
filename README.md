### 🇬🇧 English

# J.M. Intelligent Management

A full-stack web platform for a document management and consulting company, featuring:

- Institutional landing page
- Digital product sales
- Blog for publishing and sharing content

## Planned Tech Stack

| Area | Technologies |
|---|---|
| Frontend | Vite, React, React Router, Tailwind CSS |
| Backend | Node.js, Express |
| Authentication & Security | JWT, bcrypt |
| Payments | Mercado Pago |
| Email Services | Nodemailer |
| Database | PostgreSQL |
| File Storage | AWS S3 |

## Project Status

Under development.

# J.M. Gestão Inteligente

Plataforma web full-stack para uma empresa de assessoria documental, reunindo:

- Landing Page para apresentação institucional
- Venda de produtos digitais
- Blog para divulgação de conteúdo

| Área | Tecnologias |
|---|---|
| Frontend | Vite, React, React Router e Tailwind CSS |
| Backend | Node.js e Express |
| Autenticação e Segurança | JWT e bcrypt |
| Pagamentos | Mercado Pago |
| Envio de Emails | Nodemailer |

| Storage | AWS S3 |
